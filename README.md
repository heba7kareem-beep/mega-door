# ميكا للأبواب - الموقع الإلكتروني

كتالوج إلكتروني لأبواب شركة ميكا (داخلية وخارجية) - بدون سلة مشتريات أو دفع إلكتروني، التواصل عبر واتساب فقط.

## التقنيات

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- Supabase (سيُضاف لاحقاً - المرحلة القادمة)

## تشغيل المشروع محلياً

> ملاحظة: بيئة العمل السحابية الحالية لا تملك وصولاً لسجل npm (registry.npmjs.org) بسبب
> إعدادات الشبكة، لذلك لم يتم تشغيل `npm install` هناك. شغّل الأوامر التالية على جهازك:

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

### البناء للإنتاج

```bash
npm run build
npm run preview
```

## هيكل المشروع

```
src/
  components/   مكونات مشتركة (الهيدر، الفوتر، زر واتساب، بطاقة المنتج...)
  pages/        صفحات الموقع (الرئيسية، الأقسام، تفاصيل الموديل، البحث...)
  data/         بيانات الموديلات (تجريبية حالياً - ستُستبدل بـ Supabase)
  lib/          أدوات مساعدة (روابط واتساب، Meta Pixel، SEO)
  types/        أنواع TypeScript
public/
  images/models/  صور الموديلات (SVG توضيحية مؤقتة)
  robots.txt, sitemap.xml
```

## البيانات التجريبية

الملف `src/data/models.ts` يحتوي 8 موديلات تجريبية (4 داخلية + 4 خارجية) بصور SVG توضيحية
مؤقتة تم توليدها بالسكربت `scripts/gen-placeholders.mjs`. بعد استلام الصور والمحتوى الحقيقي،
سيتم استبدال هذا الملف بربط حقيقي مع Supabase عبر لوحة الإدارة.

## واتساب

رقم الشركة `07751420001` محوّل للصيغة الدولية `9647751420001` في `src/lib/whatsapp.ts`.
زر "استفسار" في كل موديل يفتح واتساب مع رسالة جاهزة تحتوي اسم ورقم الموديل.

## Meta Pixel

الغلاف الجاهز موجود في `src/lib/metaPixel.ts` مع نقاط التتبع (PageView, ViewContent, Contact)
مربوطة بالفعل في الكود، لكنها غير مفعّلة حتى تُضاف رقم Pixel حقيقي في `index.html`.

## SEO

- عناوين وأوصاف ديناميكية لكل صفحة (`src/lib/seo.ts`)
- Schema.org للشركة (في `index.html`) ولكل موديل (في صفحة التفاصيل)
- `robots.txt` و `sitemap.xml` أساسيان في `public/`
- Alt نصي لكل صورة، روابط نظيفة (`/interior`, `/model/md-101`...)
- ملاحظة: بما أن الموقع تطبيق React من جهة العميل (SPA)، الفهرسة الكاملة من محركات البحث
  تتحسن أكثر عبر Prerendering أو SSR لاحقاً - نقطة نناقشها عند الاقتراب من مرحلة الـ Deploy.
